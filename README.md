# Network-Resilience-Simulator

Python tool for visualizing graph theory algorithms and network resilience, submission for toller prize 2026.


## Overview
This application simulates a computer network to demonstrate how data routes around hardware failures and how infrastructure is physically laid out.

## Features
* Uses Breadth-First Search (BFS), Dijkstra's Algorithm, and Kruskal's Algorithm (using Disjoint Sets / Union-Find).
* Click on nodes to simulate hardware failures, and the network will dynamically reroute and repair itself.
